## Selected engineering work

VektorDeck 1.0
Local-first Windows AI workstation manager for GGUF model intelligence, runtime safety, hardware telemetry, evidence-aware benchmarking and explainable launch recommendations.

Retro Game Vision
Evidence-driven computer-vision and market-intelligence system for Japanese retro games with provenance, uncertainty, compatibility gates and reproducible economics.

CrashScope 1.2
Local-first Windows crash diagnostics for games, hardware testing and GPU-heavy workloads. The public 1.2 release includes a native WPF/WebView2 desktop shell, ConfigTrace 1.0.1 integration, 266/266 automated .NET tests and real-machine validation on both the main AMD system and a second Windows/Intel machine.

EasyFlix 1.4 released
Public MIT-licensed Windows WPF/.NET 10 local-media application with read-only multi-drive indexing, offline/removable-drive resilience, playback state, Favorites and deterministic Add Media automation. The public 1.4.0 release passed 219 automated tests with zero build warnings, has validated installer + portable win-x64 artifacts, and completed public-source privacy sanitization. Public source and the verified v1.4.0 installer/portable release are live at https://github.com/marcelosofficial-ctrl/EasyFlix.

RevDev - active development
Native .NET 8/WPF developer infrastructure for durable multi-project AI-assisted development via Dev Relay, with guarded execution, deterministic project state, a five-provider tool hub, failure learning, progress/liveness state and local-first validation. Final release acceptance is still in progress; no public release is claimed.

MinimalClock
Small lightweight Rainmeter desktop utility focused on interface craft, measured overhead, validation and packaging.

ExactArtifact 1.0.0
Compact C#/.NET artifact-integrity utility with streaming SHA-256, deterministic directory manifests, precise mismatch reporting, CLI and WPF interfaces.

GapTrace 1.0.0
Lightweight Go network-diagnostics utility for DNS/TCP/HTTP reachability, micro-outage evidence, CSV capture and recovery-window analysis.

ConfigTrace 1.0.1
Rust configuration-change tracer with deterministic snapshots, semantic field diffs, privacy-aware redaction and an event-driven JSONL journal.
